## 二、中国市场约束（接入评估前提）

- 上期所黄金(AU)/白银(AG)期权 = **期货期权、欧式** → Black-76 直接适用（F 用期货价）
- 中金所股指期权(IO/MO/HO) = 欧式、现金交割 → BS-Merton（需自估 r）
- CTP 行情无 IV 字段 → **IV 必须自算**；行情快照无行权价/期权类型字段（合约名携带）
- 期权链 = (品种, 到期月, 行权价, 方向) 四元组，无连续合约
- 中国市场规则空白：涨跌停、组合保证金、行权指派——所有开源库都不支持，必须自建

## 三、接入难度分级

**🟢 容易（纯数学，写一个 CTP tick→参数适配即可）**
1. implied-vol——首个接入目标，1-2 天可上 tick 级实时 IV
2. black_scholes——同上
3. OptionStratLib——综合性最强，需写 Chain 转换器（1-2 周），建议锁版本
4. volsurf——输入 (expiry, strike, forward, IV) 网格，数据管道是主要工作量
5. stochastic-rs / RustQuant——零件库（情景模拟/高阶 Greeks 验证）

**🟡 中等（行情适配层 + 自建交易层）**
6. market-maker-rs——卖方报价研究底座，需自写 CTP 交易网关
7. Option-Chain-OrderBook——本地仿真撮合，CTP 五档灌入即可
8. barter-rs——骨架参考，需扩期权资产类型

**🔴 不建议魔改**
9. hftbacktest（crypto L2/L3 模型 vs CTP 0.5s 快照 L1，排队模拟无意义，借鉴思想即可）
10. deribit 系 / options-market-making-engine-rs（深度耦合，当蓝图读）
11. rust-ibapi（不接入，当期权链接入教科书读）

## 四、买方/卖方策略研究路线

### 买方（方向性/波动率买入）
- 实时 IV+单腿 Greeks：implied-vol / black_scholes（tick 级）
- IV 便宜/贵判断：volsurf（ATM 期限结构+skew）+ 自建 Parquet 算 HV/EWMA/GARCH
- 策略构建：OptionStratLib（Long Straddle/Strangle、盈亏平衡、概率分析）
- 情景模拟：stochastic-rs（GARCH/Heston 路径→到期盈亏分布）
- 要点：黄金 IV 分位数、议息事件前 Vega 买入、买方最大亏损=权利金画像

### 卖方（备兑/担保卖出/波动率卖出/做市）
- 组合策略建模：OptionStratLib（Covered Call、Collar、Iron Condor、多资产组合）
- 保证金：OptionStratLib SPAN 式骨架 + **上期所/中金所组合保证金公式自写**
- 报价模型：market-maker-rs（A-S/GLFT）
- 无套利底座：volsurf（找偏离曲面的报价机会）
- 链级仿真：Option-Chain-OrderBook（先仿真后模拟盘）
- 要点：delta 对冲成本（分钟级再平衡）+ 尾部风险；先 openctp/TTS 模拟盘

## 五、Rust 衍生品生态短板与自建路线

**短板**：无 QuantLib 等价物；无 py_vollib 式工业标准小工具（建议用 py_vollib 交叉验证精度）；期权历史数据管道为零；回测框架期权支持弱（无行权/指派/除权事件）；中国市场规则空白；高阶风险报表工具缺。

**渐进式自建路线**（复用现有 CTP 采集工程）：
1. 阶段一（1-2 周）：期权合约解析落 Parquet；implied-vol/black_scholes 做 tick 级 IV+Greeks；py_vollib 抽样对照
2. 阶段二（2-4 周）：收盘后 volsurf SVI 校准+无套利检查，曲面参数落 Parquet；盘中校准曲面给非活跃合约补价
3. 阶段三（4-8 周）：OptionStratLib 策略/保证金分析；分钟 K 期权回测（买方 IV 分位数过滤；卖方 delta 对冲模拟）
4. 阶段四：做市引擎（market-maker-rs 架构），先 openctp/TTS 模拟盘
5. 数值底座：热路径 f64+ndarray/faer；研究路径 rust_decimal；pyo3 暴露给 Python 研究侧
