### 6.7 验证链

- **日常 7 条**：`cargo fmt --all --check` → `cargo clippy --all-targets -- -D warnings` → `cargo nextest run` → `cargo audit` → `cargo deny --offline check` → `cargo machete` → `cargo doc --no-deps --workspace`

### 6.8 git 操作

- `git commit -m` 用**单引号**或 `-F` 文件，不用双引号（防 `!` history expansion）

### 6.9 文件操作

- 改名后**不必立即编译**，等下次有代码改动一起编译
- 脚本改文件前先 `cat`/`grep` 确认当前格式，用 `assert t.count(old) == 1` 唯一命中
