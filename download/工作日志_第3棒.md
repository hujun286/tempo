### 技术发现（踩坑记录）
1. **CTP 行情快照无期权专属字段**：CTP 6.7.7 DepthMarketDataField 里没有 StrikePrice/OptionsType/UnderlyingInstrID——这些在 InstrumentField（合约静态结构）里，行情 API 无查询接口。期权语义只能由合约名携带解析（SHFE `au2702C768` / CFFEX `IO2612-C-4400` 两种命名规则）。
2. **迭代器 break 消费陷阱**：SHFE 合约名解析初版 `for c in chars.by_ref()` 遇数字 break 时字符已被 next() 消费，导致月份丢首位（2702→702）解析全失败。修法：break 字符用 `into_iter().chain(chars)` 接回剩余流。教训：迭代器循环里 break 字符不算"未消费"。
3. BUILD_OK 假阳性：`ls 二进制存在` 不能证明编译成功，旧二进制残留会误导。改用 cargo 输出 error 过滤 + 强制 touch 重编。
4. 订阅确认回报（on_rsp_sub_market_data）计数为 0 但行情大量到达——CTP 对已订阅合约不重复回报确认，tick 到达才是订阅成功铁证（两轮期货/期权探针均复现此现象）。
