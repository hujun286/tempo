## 三、快速上手（实盘机）

```bash
# 1. 装环境（一次性）
bash tools_工具箱/一键安装Rust工具链.sh
cp tools_工具箱/cargo国内镜像配置.toml ~/.cargo/config.toml

# 2. 编译（CTP .so 版本对照见 tools_工具箱/CTP动态库版本对照.md）
cd ctp-workspace/行情数据采集
cargo build --release

# 3. 采集（真实行情，无需登录交易账号；务必北京时区）
TZ=Asia/Shanghai ./target/release/market_data_collector ./config/secrets.toml ./data_数据/分钟分片

# 4. 合并成品（13 列 Parquet，下游按列名读）
TZ=Asia/Shanghai ./target/release/market_data_collector 合并 今日
cargo run --example 读回校验      # 成品读回校验（列名/行数/黄金白银样本/缺口）
cargo run --example 缺口分析      # 缺口分布画像
```

## 四、2026-11-27 凌晨夜盘实测结论（真实行情，黄金白银窗口）

1. 16/16 行情前置 TCP 连接+登录全通，累计 tick 5 万+，0 断线；SHFE/INE 前置不挂中金所合约（探针旧版订阅 IF/IM/IC 全拒是合约口径错误，非链路问题）。
2. **发现并修复"登录重演假 bar"**：CTP 登录/重连时前置重发每合约最后一帧快照，夜盘已收品种（铜等）被重发快照生成假 bar（v2.0 过滤只拦 volume==0 拦不住带量快照）。v2.1 新增"时戳偏离过滤"（交易所戳 vs 到达时刻 >2 分钟=重演，实测 18610 个重演快照精准拦截，修复后假 bar 归零）。
3. **时区防呆**：本机非 +08:00 启动即 ERROR 挑明（沙盒 UTC 下曾整场误杀真行情，实盘机北京时间无此问题，但必须防呆）。
4. 成品 13 列 Parquet 口径统一：jsonl 中间层与成品同名 `bar_time`（老分片 alias 兼容）；读回校验/缺口分析双工具齐备；分片归档压缩实测 2580020B→200780B（12.7×）。
5. 依赖：tokio 全树 0 个；regex 仅剩 ctp2rs 构建期；arrow 拆 arrow-array/arrow-schema 子 crate；总依赖 167→109；数据库依赖（parquet/zstd）完整保留。
